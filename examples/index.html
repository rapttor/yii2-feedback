Feedback widget: examples

The same widget, started five ways. Every page has a form, a table and an alert, so you can see the consented screen data.

  • Plain HTML: one CSS file, one JS file, Feedback.init(), no server
  • Data attributes: no JavaScript of your own, posts to your endpoint (needs node examples/serve.mjs)
  • Web component: <rapttor-feedback>
  • jQuery: $.feedback(), $(el).feedback()
  • Vue 3 (and vue/FeedbackWidget.vue, vue/useFeedback.js)
  • React (and react/FeedbackWidget.jsx)
  • Svelte, Angular, Next.js, Nuxt, Alpine (snippets, not run)

Run them: node examples/serve.mjs and open http://localhost:8099/examples/ (opening the files directly also works for all but the data-attributes page). The Vue and React pages load their framework from cdnjs.
